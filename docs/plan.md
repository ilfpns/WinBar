# 앱 기획서

## 1. 앱 이름
WinBar

## 기술 스택
- 외부 NuGet 패키지를 사용하지 않는 C# 및 .NET 10 WinForms 데스크톱 앱
- Windows 10/11과 설치된 .NET 10 SDK 대상
- 시스템 정보는 Win32 API를 P/Invoke로 호출
- HTML, CSS, JavaScript 기반 앱과 웹 서버는 사용하지 않음

## 2. 사용자 (누가 쓰나)
- Windows에서 MaCBook MenuBar를 쓰고싶어하는 일반 사용자
- Windows 환경에서 깔끔한 상태바를 원하는 일반 사용자

## 3. 해결할 문제 (왜 필요한가)
- MacOS 환경에서만 사용 가능한 Menubar를 대체할 수 있는 제품을 만들기 위해
- 기존 Windows 환경에서 불편한 상태, 기능 확인 문제를 해결하기 위해

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)
  - MenuBar에서 CPU, GPU, RAM, 배터리, 시간을 포함한 노트북 상태 확인
  - MenuBar에서 Wi-Fi, Bluetooth, 음량, 화면 밝기 제어
  - 기본 macOS MenuBar에서 제공하는 주요 상태 확인 및 제어 기능 제공
  - 상태 등 빠른 자동 반영
  - 재부팅 후 설정 저장
  - 사용자 동의를 받은 Windows 로그인 시 자동 실행

## 5. 화면 구성 (위에서 아래 순서)
  - Windows MenuBar의 형태로 스크린 상단에 얇은 막대 형태로 실행됨
  - 연결된 모든 모니터의 상단에 MenuBar가 표시됨

## 6. 사용 흐름 (사용자가 하는 행동 순서)
  - 기존 MacOS MenuBar 유저가 사용하는 흐름과 같이 기본적인 호버, 클릭 등으로 확인 가능
  - 사용자가 설치 프로그램 하나로 앱을 설치하고, 설치 과정에서 자동 실행 여부에 동의함
  - Windows에 로그인하면 앱이 자동 실행되고 이전 설정이 복원됨

## 7. 만들지 않을 것
  - 기존 Windows OS의 기능을 제한하는 기능 추가
  - 노트북에 깔려있는 모든 앱의 기능을 제한하는 기능 추가
  - 노브툭에서 실행되는 모든 프로그램의 기능을 제한하는 기능 추가

## 8. 완료 기준
  - 기본 MacOS menubar같이 컴퓨터 상태를 체크할 수 있다.
  - 기존 노트북에서 실행하던 앱에 대한 기능 제약을 하지 않는다.
  - 기존 노트북 OS 기능을 제한하지 않는다.
  - 노트북을 재시작해도 알아서 OS의 원래 기능처럼 다시 켜지고, 설정이 저장된다.
  - 설치 프로그램 하나로 쉽게 설치할 수 있다.
  - 설치 과정에서 사용자가 동의한 경우에만 Windows 로그인 시 자동 실행된다.
  - 연결된 모든 모니터에 MenuBar가 표시된다.
