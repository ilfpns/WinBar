# WinBar 개인정보 처리방침

시행일: 2026년 10월 1일 · 대상: WinBar 0.1.0 (프로토타입, Windows 10/11 전용)

WinBar는 Windows 화면 맨 위에 컴퓨터 상태를 보여 주는 메뉴바 앱입니다. WinBar는 **개인정보를 수집하지 않고, 어떤 정보도 인터넷이나 외부 서버로 보내지 않습니다.**

## 1. 화면에 보여 주기 위해 읽는 정보
아래 정보는 메뉴바에 표시하기 위해 이 컴퓨터 안에서만 읽고, 저장하거나 보내지 않습니다.

| 읽는 정보 | 쓰는 곳 |
| --- | --- |
| CPU · GPU · 메모리 사용률, 배터리 잔량과 충전 상태 | 메뉴바 상태 표시 |
| 연결된 Wi-Fi 이름과 신호 세기, 유선 연결 여부 | 네트워크 표시 |
| Bluetooth 켜짐 여부와 연결된 기기 이름 | Bluetooth 표시 |
| 음량, 화면 밝기 | 표시와 조절 |
| 카메라·마이크를 지금 쓰고 있는지 여부(Windows 개인 정보 설정 기록) | 사용 중 표시(초록·주황 점) |
| 현재 입력 언어와 한/영 상태 | 한/영 스위치 표시 |

## 2. 키보드와 마우스 입력
- WinBar는 **한/영 키, Esc 키, 마우스 버튼을 눌렀다는 사실**만 감지합니다. 한/영 표시를 바로 바꾸고, 열린 메뉴를 닫기 위해서입니다.
- 다른 키를 무엇을 눌렀는지, 입력한 글자는 기록하거나 저장하지 않습니다. 입력을 가로채거나 막지도 않습니다.

## 3. 저장하는 정보
- 사용자가 고른 화면 설정(표시할 항목, 24시간 시계, 배경 불투명도)만 이 컴퓨터의 `%LOCALAPPDATA%\WinBar\settings.ini`에 저장합니다.
- 로그인 시 자동 실행은 사용자가 직접 켠 경우에만 동작합니다.

## 4. 외부 전송과 제3자 제공
- WinBar에는 인터넷으로 데이터를 보내는 기능이 없습니다. 광고, 분석, 추적 도구도 넣지 않았습니다.
- 어떤 정보도 제3자에게 제공하지 않습니다.

## 5. 삭제
앱을 제거하면 앱과 설정이 함께 지워집니다. 직접 지우려면 `%LOCALAPPDATA%\WinBar` 폴더를 삭제합니다.
