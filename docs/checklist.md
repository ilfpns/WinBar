## 회귀 점검표

`AGENTS.md`의 확인 절차와 완료 기준 ①~⑦을 바탕으로 한 점검표입니다. 모든 항목은 `dotnet build WinBar.csproj -c Release`로 만든 `bin\Release\net10.0-windows\WinBar.exe`를 일반 사용자 권한으로 실행해 확인합니다.

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
| --- | --- | --- | --- | --- |
| 0-1 | 빌드 오류 없음 | 터미널에서 `dotnet build WinBar.csproj -c Release`를 실행한다. | 마지막 줄에 `경고 0개`, `오류 0개`가 나온다. | |
| 0-2 | 실행 중 처리되지 않은 오류 없음 | WinBar를 실행하고 5분 동안 로고 메뉴·설정·음량·밝기·Wi-Fi·Bluetooth 팝업을 한 번씩 열고 닫는다. 이어서 `이벤트 뷰어 > Windows 로그 > 응용 프로그램`에서 최근 10분의 `.NET Runtime`·`Application Error` 항목을 확인한다. | WinBar가 계속 떠 있고, 이벤트 로그에 `WinBar.exe` 오류 항목이 없다. | |
| ①-1 | 모든 모니터 상단 표시 | 모니터 1대 상태에서 WinBar를 실행한다. 외부 모니터가 있으면 연결한 상태에서 다시 실행한다. | 연결된 모든 모니터의 맨 위에 높이가 같은 메뉴바가 하나씩 보인다. | |
| ①-2 | 모니터 연결 변경 | WinBar를 실행한 채 외부 모니터를 연결했다가 5초 뒤 분리한다. | 연결하면 새 모니터에 메뉴바가 생기고, 분리해도 남은 모니터의 메뉴바가 정상 표시된다. | |
| ②-1 | CPU·GPU·RAM 표시 | 메뉴바의 CPU 칩 아이콘에 마우스를 올린다. | `시스템 사용량` 팝업에 CPU·GPU·메모리가 각각 `숫자%`로 나오고, 2초 뒤 값이 다시 갱신된다. | |
| ②-2 | 배터리 표시 | 노트북에서 충전기를 연결한 상태와 뺀 상태로 메뉴바 오른쪽 배터리를 본 뒤 배터리 아이콘에 마우스를 올린다. | 퍼센트와 배터리 아이콘이 보이고, 충전 중에는 번개가 표시된다. 충전기를 빼면 팝업에 `남은 시간`이 나온다. | |
| ②-3 | 네트워크 표시 | Wi-Fi에 연결된 상태에서 Wi-Fi 아이콘에 마우스를 올린 뒤, Windows 빠른 설정에서 Wi-Fi를 끈다. 확인 후 다시 켠다. | 연결 중에는 네트워크 이름과 신호 세기가, 끈 뒤에는 `연결 안 됨`이 표시된다. | |
| ②-4 | 음량·시간 표시 | 키보드 음량 키로 음량을 한 칸 올렸다가 내리고, 메뉴바 오른쪽 끝 시계를 Windows 작업 표시줄 시계와 비교한다. | 음량 아이콘이 1초 안에 바뀌고, 시계가 `10월 1일 (목) 오후 1:44` 형식으로 작업 표시줄과 같은 시각을 보여 준다. | |
| ③-1 | 음량 제어 | 음량 아이콘을 눌러 팝업의 슬라이더를 가운데로 끈다. 스피커 아이콘을 눌러 음소거했다가 다시 누른다. | Windows 음량이 약 50%로 바뀌고, 음소거·해제가 Windows 음량 표시와 같게 바뀐다. | |
| ③-2 | 밝기 제어 | 노트북 내장 화면에서 밝기 아이콘을 눌러 슬라이더를 90% 위치로 옮긴 뒤 다시 100%로 옮긴다. | 화면 밝기가 실제로 어두워졌다가 돌아온다. 밝기를 지원하지 않는 화면이면 팝업에 지원하지 않는다는 문구가 나온다. | |
| ③-3 | Wi-Fi·Bluetooth 설정 연결 | Wi-Fi 아이콘 팝업에서 `네트워크 설정…`을, Bluetooth 아이콘 팝업에서 `Bluetooth 설정…`을 누른다. | 각각 Windows 설정의 Wi-Fi 화면과 Bluetooth 화면이 열리고, WinBar가 Wi-Fi·Bluetooth를 직접 끄거나 켜지 않는다. | |
| ④-1 | 동의 없이는 자동 실행 안 함 | 설정 > 일반에서 `로그인 시 자동 실행`이 꺼진 상태로 두고 Windows를 재부팅한 뒤 로그인한다. | WinBar가 자동으로 실행되지 않는다. | |
| ④-2 | 동의 시 자동 실행 | 설정 > 일반에서 `로그인 시 자동 실행`을 켜고 재부팅한 뒤 로그인한다. 확인 후 다시 끈다. | 로그인 후 메뉴바가 자동으로 나타난다. | |
| ④-3 | 설정 복원 | 설정 > 모양에서 배경 불투명도를 40%로, 설정 > 메뉴바 항목에서 `Bluetooth`를 끈다. 로고 메뉴 > `WinBar 종료` 후 다시 실행한다. 확인 후 원래대로(60%, Bluetooth 켬) 되돌린다. | 다시 실행해도 불투명도 40%와 Bluetooth 숨김이 유지된다. | |
| ⑤ | 설치 프로그램으로 설치·제거 | 설치 프로그램 하나를 실행해 설치하고, Windows `설정 > 앱`에서 WinBar를 제거한다. | 설치 후 시작 메뉴에서 실행되고, 제거하면 프로그램 파일과 자동 실행 등록이 남지 않는다. (현재 미구현) | |
| ⑥-1 | 유휴 CPU 1% 이하 | WinBar를 새로 실행하고 아무것도 누르지 않은 채 5분 동안 작업 관리자 `세부 정보` 탭의 WinBar.exe CPU 열을 지켜본다. | 대부분 0%이며 평균이 1%를 넘지 않는다. | |
| ⑥-2 | 메모리 40MB 이하 | ⑥-1과 같은 5분 동안 작업 관리자 `세부 정보` 탭에 `작업 집합(메모리)` 열을 추가해 WinBar.exe 값을 본다. | 측정 내내 40MB 이하이다. | |
| ⑥-3 | 상태 갱신 주기 2초 이상 | CPU 아이콘 팝업을 띄운 채 숫자가 바뀌는 간격을 휴대폰 초시계로 10번 잰다. | 숫자는 2초보다 짧은 간격으로 바뀌지 않는다. | |
| ⑦-1 | 최대화한 창을 가리지 않음 | 메모장을 열고 최대화한다. | 메모장 제목 표시줄과 닫기 단추가 메뉴바 바로 아래에 보이고 가려지지 않는다. | |
| ⑦-2 | 전체 화면 앱 방해 안 함 | 브라우저에서 F11을 눌러 전체 화면으로 만든 뒤 마우스를 화면 맨 위에 댔다가 아래로 내린다. 확인 후 F11로 되돌린다. | 전체 화면이 되면 메뉴바가 위로 숨고, 마우스를 맨 위에 대면 내려왔다가 내리면 다시 숨는다. | |
| ⑦-3 | 센서 오류가 전체를 멈추지 않음 | `소리 설정`에서 기본 출력 장치를 사용 안 함으로 바꾸고 1분 동안 메뉴바를 본다. 확인 후 다시 사용으로 바꾼다. | 음량만 표시가 바뀌거나 비고, 시계·CPU·배터리 등 나머지는 계속 갱신되며 WinBar가 종료되지 않는다. | |
