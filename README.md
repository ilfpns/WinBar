# WinBar

Windows 10/11용 macOS 스타일 메뉴바입니다.
연결된 모든 모니터 상단에 컴퓨터 상태를 보여 주고, 음량·밝기를 바로 조절할 수 있습니다.

![WinBar](screenshot.png)

## 실행
.NET 10 SDK가 필요합니다. 관리자 권한은 필요 없습니다.

```powershell
dotnet build WinBar.csproj -c Release
.\bin\Release\net10.0-windows\WinBar.exe
```

## 기능
- **상태 표시**: 카메라·마이크 사용 중 표시, 입력 소스(한/A 스위치), Wi-Fi·유선, Bluetooth, CPU·GPU·메모리, 음량, 밝기, 배터리(남은 시간), 시계
- **제어**: 음량·밝기 슬라이더, Wi-Fi·Bluetooth·사운드·디스플레이는 Windows 설정으로 연결
- **디자인**: macOS처럼 배경화면이 비치는 반투명(흐림) 배경, 굵은 아이콘, 오른쪽 끝 시계(`10월 1일 (목) 오후 1:44`)
- **설정**: 왼쪽 로고 → 설정(바깥을 누르면 메뉴가 닫힘). 일반(자동 실행·24시간 시계), 모양(배경 불투명도 20~100%), 메뉴바 항목, 정보
- **전체 화면**: 메뉴바가 위로 숨고, 마우스를 화면 맨 위에 대면 다시 내려옴
- 메뉴바 높이만큼 화면을 비워 두어 최대화한 창을 가리지 않음

## 성능 (Release, 시작 직후부터 5분 30초 측정)
| 항목 | 기준 | 측정값 |
| --- | --- | --- |
| 유휴 CPU | 평균 1% 이하 | 0.17% |
| 메모리(작업 집합) | 40MB 이하 | 최대 34.2MB |
| 상태 갱신 | 2초 이상 | 2초 (음량·밝기·카메라는 변경 알림으로 반영) |

설정은 `%LOCALAPPDATA%\WinBar\settings.ini`에만 저장되며 외부로 보내지 않습니다.
