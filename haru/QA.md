Haru를 점검한 기록. 새 항목은 맨 위에 적는다. 문제는 번호를 붙이고, 처리 결과(고침 / 보류 / 사양대로)를 함께 적는다.

## 2026-10-24 (v1.58) — 상태 아이콘 바뀜(이전 → 새)

요청: 이름 뒤 상태 아이콘이 바뀌는 애니메이션.

**원인과 처리**
1. 편집기에서 상태를 바꾸면 다이얼은 초안(draft)을 그리는데, 바뀜 감지는 저장된 할 일만 봐서 저장 전에는 안 움직였음 → 감지를 화면에 보이는 할 일(초안 포함) 기준으로.
2. 새 배지만 튀어서 "바뀌는" 느낌이 약함 → 바뀌는 동안 이전 배지를 함께 그려 돌며 작아져 사라지게(badge-out), 새 배지는 150ms 뒤 튀어나옴. 끝나면 다시 그려 이전 배지 제거.

**확인한 것** (개발 서버, 조각 보기) — 편집기에서 진행 중 고르기(저장 전): [시작 전 leaving, 진행 중 pop] → 1.6초 뒤 [진행 중]. 목록 칸으로 바꿔도 같음. 콘솔 오류 없음, `npm run build` 통과.

1. 캘린더가 6주짜리 달에 화면 높이가 낮으면(720px) 마지막 주가 카드 아래로 잘림 — **고침**: 그리드가 카드 안에서 스크롤.
2. 휴대폰에서 캘린더의 달 이동 버튼(‹ Today ›)이 제목 "October 2026" 위에 겹침 — **고침**: 좁으면 버튼 줄이 제목 아래로 내려감.
3. 휴대폰에서 Journal 폴더 목록이 눌려 사라지고 편집기까지 스크롤이 안 됨(Words도 같은 구조) — **고침**: 좁은 화면에서는 페이지 전체가 스크롤.
4. 같은 이름의 폴더를 여러 개 만들 수 있음 — **고침**: 만들기·이름 바꾸기 때 막고 안내.
5. 편집기에서 완료를 누르면 임시본에만 반영돼 목록의 체크와 어긋남 — **고침**: 저장된 작업은 바로 완료 처리(목록·다이얼·편집기 일치).
6. 한국어 모드에서 번역 안 된 문구: 글 속 사진의 복사/지우기 버튼, "Photo removed", 폴더 메뉴 도움말, "A template of Today" — **고침**.
7. 터치 기기에서 템플릿·단어 카드의 삭제 버튼이 너무 작음(20px) — **고침**: 28px.
8. 뉴스 서랍의 주제·출처 이름(Nvidia, Cybersecurity 등)은 한국어 모드에서도 영어 — **사양대로**(데이터 그대로).
9. 휴대폰에서 출석 잔디가 가로로 잘려 보임 — **사양대로**(옆으로 스크롤, 이번 주가 보이게 열림).
