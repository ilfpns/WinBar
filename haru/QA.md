# QA 로그

Haru를 점검한 기록. 새 항목은 맨 위에 적는다. 문제는 번호를 붙이고, 처리 결과(고침 / 보류 / 사양대로)를 함께 적는다.
점검은 사용자의 브라우저가 아니라 별도의 헤드리스 브라우저(gstack browse, `http://localhost:5288`)에서 한다.

## 2026-10-19 (v1.11)

**찾은 문제와 처리** (사용자 제보)
1. 일기 목록 폭을 넓히면 편집기 위 버튼 줄이 카드 밖으로 밀림 — **고침**: 패널 최소 폭 0, 머리 줄바꿈. 최대 폭에서 버튼 끝 1185px < 카드 끝 1204px 확인.
2. 나의 하루들 위 경계가 안 움직임(접힌 상태에선 높이가 적용되지 않음) — **고침**: 접혀 있으면 경계를 숨기고, 펼치면 374→294px로 조절 확인.
3. 경계를 누르면 배경 클릭으로 처리돼 왼쪽 서랍이 열림 — **고침**: 경계는 배경 클릭에서 제외. 좌우·위아래 모두 서랍 안 열림 확인.

3. 목록 보기 정리 중 지워지지 않은 줄로 문법 오류 — **고침**.

**아직 못 본 것**

4. 로고 서비스가 없는 사이트에도 기본 그림(48px, 404)을 줘서 로고가 있는 것처럼 보임 — **고침**: 기본 그림이면 고리 아이콘.
5. 설정의 계정 카드·백업 안내·데이터 설명이 로그인해도 "로컬 · 로그인 꺼짐" — **고침**.

## 2026-10-19

**확인한 것**
- 빌드(`npm run build`)와 타입 검사 통과, 모든 페이지에서 콘솔 오류 없음.
- 페이지 6개(Today·Calendar·News·Words·Journal·Archive)를 1280×720과 390×844(휴대폰)에서 화면으로 확인. 라이트 테마, 한국어 모드도 확인.
- Today: 할 일 목록에서 편집기 열기, 메모 쓰기, 완료 표시(배지·점), 목록에서 체크 해제 시 편집기 동기화, 템플릿 "From today" 저장 → Use → Undo, 오른쪽 서랍이 Today 탭으로 열림, 단축키 `]`·Esc, 새로고침 뒤 데이터 유지.
- Calendar: 날짜 선택, 메모에 `! 09:00~09:30 work …` 입력 → Today에 작업 추가, 통계 보기.
- News: 출석 체크·취소, 헤드라인 서랍(300개), 갱신 시각 표시.
- Words: 뒤집기, Got it, 단어 추가, 검색.
- Journal: 새 페이지, 새 폴더, 나의 하루들 펼치기/접기, 글 속 사진(붙여넣기·클릭·복사·삭제·되돌리기).
- Settings: 테마·언어 전환, 백업 내보내기(파일 생성), 학교·반 선택 목록, 하루 시작 시각.

**찾은 문제와 처리**
1. 캘린더가 6주짜리 달에 화면 높이가 낮으면(720px) 마지막 주가 카드 아래로 잘림 — **고침**: 그리드가 카드 안에서 스크롤.
2. 휴대폰에서 캘린더의 달 이동 버튼(‹ Today ›)이 제목 "October 2026" 위에 겹침 — **고침**: 좁으면 버튼 줄이 제목 아래로 내려감.
3. 휴대폰에서 Journal 폴더 목록이 눌려 사라지고 편집기까지 스크롤이 안 됨(Words도 같은 구조) — **고침**: 좁은 화면에서는 페이지 전체가 스크롤.
4. 같은 이름의 폴더를 여러 개 만들 수 있음 — **고침**: 만들기·이름 바꾸기 때 막고 안내.
5. 편집기에서 완료를 누르면 임시본에만 반영돼 목록의 체크와 어긋남 — **고침**: 저장된 작업은 바로 완료 처리(목록·다이얼·편집기 일치).
6. 한국어 모드에서 번역 안 된 문구: 글 속 사진의 복사/지우기 버튼, "Photo removed", 폴더 메뉴 도움말, "A template of Today" — **고침**.
7. 터치 기기에서 템플릿·단어 카드의 삭제 버튼이 너무 작음(20px) — **고침**: 28px.
8. 뉴스 서랍의 주제·출처 이름(Nvidia, Cybersecurity 등)은 한국어 모드에서도 영어 — **사양대로**(데이터 그대로).
9. 휴대폰에서 출석 잔디가 가로로 잘려 보임 — **사양대로**(옆으로 스크롤, 이번 주가 보이게 열림).
